# История изменений

## 2.0.0 — 2026-09-16

Глобальное изменение: мультиисточниковый подход и переход на SQLite.

### Добавлено

- **Несколько источников репозиториев.** Пользователь добавляет любое число
  серверов — корпоративный GitLab, github.com, GitHub Enterprise Server —
  и переключается между ними в главном окне. У каждого источника свои настройки:
  название, адрес API, access token, директория хранения кода, путь к SSH-ключу,
  число параллельных операций.
- **Поддержка GitHub** (`app/core/github_client.py`): список репозиториев через
  REST API (`/user/repos`, пагинация по заголовку `Link`), Bearer-аутентификация,
  фильтрация архивных, доступность кода по `permissions.pull`, обработка
  rate limit и SSO-ограничений; поддержка GitHub Enterprise через адрес API.
- **Единый слой провайдеров** (`app/core/provider.py`): общий `Project`,
  базовое исключение `ProviderError`, фабрика клиентов `make_client` —
  добавление нового типа сервера сводится к новому клиенту.
- **Хранилище SQLite** (`app/core/storage.py`, `%APPDATA%\GetGit\getgit.db`):
  таблицы `profiles` (источники), `settings` (глобальные настройки),
  `sync_state` (дата и результат последней синхронизации по каждому
  репозиторию каждого источника).
- **Автоматическая миграция настроек v1**: при первом запуске `config.json` и
  `state.json` переносятся в базу (включая токен — он копируется в новую запись
  Диспетчера учётных данных), старые файлы переименовываются в `*.bak`.
- UI: выпадающий список «Источник», диалог «Источники…» (добавление, изменение,
  удаление) и диалог редактирования источника с подсказками под тип сервера.

### Изменено

- Токены хранятся в Диспетчере учётных данных Windows по одной записи на источник
  (`GetGit` / `profile-<id>`), как и раньше — не в файлах и не в базе.
- Дата последнего обновления и статус репозиториев ведутся раздельно по источникам.
- Диалог «Настройки…» заменён на «Источники…»; глобальной осталась только отметка
  «Показывать недоступные репозитории».

### Удалено

- `config.json`/`state.json` как основное хранилище (остаются только резервные
  копии `*.bak` после миграции); `app/ui/settings_dialog.py`.

## 1.1.0 — 2026-09-16

- Отметка «Показывать недоступные репозитории» на главном окне.
- Строгое зеркалирование: `git clean -fd` заменён на `-fdx` — удаляются
  и ignored-файлы, локальная копия точно повторяет сервер.
- План поддержки GitHub (PLAN_GITHUB.md).

## 1.0.0 — 2026-08-18

- Первый релиз: зеркалирование репозиториев корпоративного GitLab (клонирование
  по SSH, полная синхронизация веток), список репозиториев через GitLab API,
  лог операций, параллельное обновление, хранение токена в Диспетчере учётных
  данных, сборка в один exe (PyInstaller), иконка, окно «О программе»,
  корректное завершение фоновых git-процессов при выходе.
